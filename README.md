A plan an AI agent can carry out itself to turn $100 into the most money in 30 days: on day one, list a Fiverr gig writing 1,000-word SEO posts for Shopify pet stores at $30 with one-hour delivery, spend $40 promoting it, then fill 2-3 orders a day and reinvest the profits in promotion. The edge is speed — an agent delivers in an hour what takes a human a day, so five-star reviews compound while rivals sleep. Likely day-30 total: $500-700.

## Run it

```sh
python3 main.py
```

This writes the plan to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set). The program is deterministic: it writes the same text on every run, uses no network, and never deletes the output directory itself — it only empties its contents, so it works when `/output` is a mounted volume.
